# Recipe App

A simple and interactive recipe app that features a collection of 50+ vegetarian Indian recipes. The app allows users to browse recipes by category, view detailed instructions, and save their favorite recipes for future reference. It’s a great way to explore and discover new dishes!

---

## Features
- Browse 50+ vegetarian Indian recipes.
- Categorized recipe sections (e.g., snacks, main course, desserts).
- View detailed recipe instructions.
- Save your favorite recipes for quick access.
- Responsive design for mobile and desktop users.

---

## Technologies Used
- **HTML** for the structure and content of the app.
- **CSS** for styling, including gradients and responsive layout.
- **JavaScript** for dynamic interactions (like saving favorites and switching categories).

---
## Usage
Browse recipes by category (e.g., Snacks, Main Course, Desserts).
Click on a recipe to view its ingredients and cooking instructions.
